# Variation & Additional Work Register

A shared web register for tracking construction variations under Clause 20 of the
HIA Queensland New Homes Construction Contract, for Walter Design & Development Pty Ltd.

Open the GitHub Pages link to use it. Builder view adds/manages variations (passcode-lockable);
Owner view reviews and signs each variation (draw or upload a signature). Each building gets its
own link via Projects -> New project (?p=<token>).
